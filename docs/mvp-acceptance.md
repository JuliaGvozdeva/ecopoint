# Критерии приёмки MVP

- [ ] Пользователь может искать пункты по названию и адресу.
- [ ] Фильтры по материалам работают с определённой семантикой AND/OR.
- [ ] Карта и список отображают согласованные результаты.
- [ ] У пункта есть постоянный URL.
- [ ] Неизвестные условия приёма не отображаются как подтверждённый отказ.
- [ ] Предложения пользователей не меняют каталог без модерации.
- [ ] Все административные операции проверяются на backend.
- [ ] Есть unit-, integration- и E2E-покрытие ключевых сценариев.
- [ ] Приложение собирается и проходит typecheck в CI.
- [ ] Есть инструкция запуска с нуля и описание источников данных.
