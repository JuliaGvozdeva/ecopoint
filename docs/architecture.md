# Архитектура EcoPoint

## Принципы
- Модульный монолит, без микросервисов на MVP.
- `apps/web` отвечает за UI и клиентское состояние.
- `apps/api` отвечает за бизнес-правила, доступ к данным и интеграции.
- `packages/contracts` хранит публичные схемы/DTO, общие для frontend и backend.
- Prisma-модели не импортируются во frontend.
- Внешние источники не вызываются из браузера напрямую для каждого поиска.

## Предлагаемые модули API
- `places`: каталог, детали, поиск.
- `materials`: справочник материалов.
- `suggestions`: публичные предложения.
- `moderation`: административные решения.
- `imports`: загрузка, нормализация и дедупликация данных.

## Данные
Планируем PostgreSQL + PostGIS. Пространственные запросы должны использовать параметризованные SQL-запросы и подходящий spatial index. Импорт OSM должен быть повторяемым и сохранять source ID и время загрузки.
